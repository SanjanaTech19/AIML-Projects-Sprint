Customer Segmentation Using K-Means

📝 About the Project

Customer segmentation occurs when a business divides its consumer base into distinct groups based on shared characteristics. Targeting specific segments with tailored campaigns yields significantly higher conversion rates than using a generic, one-size-fits-all approach.This project addresses the problem by analyzing historical customer income data, purchasing behaviors, and age demographics. By training an unsupervised clustering model, the project helps businesses flag behavioral patterns and deploy targeted incentive or marketing campaigns to maximize customer lifetime value.

🛠️ Tools and Technologies Used 

The project is built entirely in Python using the following stack:

Data Manipulation: NumPy & Pandas
Data Visualization: Matplotlib & Seaborn
Machine Learning: Scikit-Learn

📊 About the Dataset

The model utilizes the popular Mall Customers dataset (commonly sourced from Kaggle). It contains structured profiles of 200 unique customers tracking a combination of age, gender, annual income, and an internal customer spending score.
