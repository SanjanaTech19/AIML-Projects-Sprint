# Parkinson's Prediction

This project builds a machine learning model to predict Parkinson's disease using the Parkinson's dataset.

## Project Structure
- `model.ipynb` - Jupyter notebook with data exploration, preprocessing, model training, and evaluation
- `parkinsons.data` - Dataset file (ignored by Git)

## Setup
1. Create and activate a virtual environment
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `model.ipynb` in Jupyter Notebook or JupyterLab

## Dependencies
The project uses:
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
